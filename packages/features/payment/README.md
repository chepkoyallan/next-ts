# Payment Plugin

## Overview

This plugin provides payment processing and integration functionality for the application.

## Features

- Payment processing
- Multiple payment methods
- Transaction management
- Payment history
- Integration with the plugin system

## Installation

This plugin is part of the monorepo and is automatically available.

## Usage

```typescript
import { ... } from '@app/payment';
```

## Configuration

Plugin configuration is defined in `plugin.json`.
