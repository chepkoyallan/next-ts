# Tour Plugin

## Overview

This plugin provides guided tours and onboarding functionality for the application.

## Features

- Interactive tours
- Step-by-step guides
- User onboarding
- Feature highlights
- Integration with the plugin system

## Installation

This plugin is part of the monorepo and is automatically available.

## Usage

```typescript
import { ... } from '@app/tour';
```

## Configuration

Plugin configuration is defined in `plugin.json`.
