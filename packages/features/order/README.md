# Order Management Plugin

## Overview

This plugin provides order processing and tracking functionality for the application.

## Features

- Order creation
- Order tracking
- Order status management
- Order history
- Integration with the plugin system

## Installation

This plugin is part of the monorepo and is automatically available.

## Usage

```typescript
import { ... } from '@app/order';
```

## Configuration

Plugin configuration is defined in `plugin.json`.
