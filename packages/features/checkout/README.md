# Checkout Plugin

## Overview

This plugin provides shopping cart checkout functionality for the application.

## Features

- Cart management
- Checkout process
- Payment integration
- Order confirmation
- Integration with the plugin system

## Installation

This plugin is part of the monorepo and is automatically available.

## Usage

```typescript
import { ... } from '@app/checkout';
```

## Configuration

Plugin configuration is defined in `plugin.json`.
