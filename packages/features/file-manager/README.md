# File Manager Plugin

## Overview

This plugin provides file upload and management functionality for the application.

## Features

- File upload
- File organization
- File preview
- Access control
- Integration with the plugin system

## Installation

This plugin is part of the monorepo and is automatically available.

## Usage

```typescript
import { ... } from '@app/file-manager';
```

## Configuration

Plugin configuration is defined in `plugin.json`.
