# Job Board Plugin

## Overview

This plugin provides job posting and application management functionality for the application.

## Features

- Job listings
- Application management
- Candidate tracking
- Job search and filtering
- Integration with the plugin system

## Installation

This plugin is part of the monorepo and is automatically available.

## Usage

```typescript
import { ... } from '@app/job';
```

## Configuration

Plugin configuration is defined in `plugin.json`.
